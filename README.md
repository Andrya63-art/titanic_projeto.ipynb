# 📊 Análise de Dados e Machine Learning - Titanic

Projeto desenvolvido com foco em análise de dados e aplicação de modelos de machine learning para prever a sobrevivência de passageiros do Titanic.

## 🎯 Objetivo
Trabalhar etapas completas de análise de dados: limpeza, transformação e modelagem.

## 🛠️ Tecnologias
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## ⚙️ Etapas
- Leitura e análise dos dados
- Tratamento de valores nulos
- Criação de variáveis
- Treinamento de modelos
- Avaliação de desempenho


## ⚠️ Aviso
Projeto desenvolvido para prática e aprendizado na área de dados.
